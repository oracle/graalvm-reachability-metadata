# Coverage notes

The tests exercise XML bean conversion, legacy configurator compatibility,
implementation hints, arrays, collections, field and setter configuration,
class conversion, and container registration and classpath configuration.
Class realms delegate to the existing test classloader; no test adds classes
or JARs to a realm.

Two call sites intentionally remain uncovered:

- `AbstractConfigurationConverter.loadClass` is reached only by its protected
  `instantiateObject(String, ClassLoader)` overload, which has no callers in
  the shipped implementations. Exposing it solely for coverage would not
  exercise consumer-facing behavior.
- Shaded ASM `ClassWriter.getCommonSuperClass` participates in stack-frame
  computation for generated bytecode. Testing runtime bytecode generation or
  exposing this protected helper solely for coverage would violate the test
  contract, so no such test is added.
